## AI Arcade: playable static v1 prototype

Adds three mobile-friendly AI literacy games and twelve fictional scenarios from SPEC.md. Shared screens support two-stage privacy/bias decisions, source-checking questions, first-attempt scoring, a practice retry, answer explanations, results and replay. Scenario content and references are editable separately from UI code.

Includes a self-contained Vite/TypeScript build, exact Mac setup instructions, engine/content tests and desktop/phone browser tests with axe checks.

Content-source verification remains pending because the cloud network policy blocked the four publisher domains. See REVIEW.md for evidence, limits and mentor questions. Keep the PR and prototype private; no deployment or participant evaluation is included.
